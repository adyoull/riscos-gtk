# RISC OS icons for the tests

A few of the RISC OS 5 ("Sovereign") window border (tool) sprites and Wimp
sprites, as PNGs, from https://github.com/marutan/riscos-free-icons
(commit 4378564d241cc27ed09390c9fe3f123d3c54dec2): Icons/Sovereign/Tools/*22.png and
Icons/Sovereign/Sprites22/{optoff,opton,radiooff,radioon,gright,left,right,up,down}.png.

Icons are (c) RISC OS Developments Ltd and are released under the terms of
the Apache License 2.0 (LICENSE here). Unchanged.

themetest-fake loads them into the fake Wimp (TT_ICONS=this directory) to
picture the theme with real RISC OS sprites.
